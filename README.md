# Classical-Recording-Studio-
古典录音工作台把现场录音和 CD 抓轨整理成按作品、乐章和场次归档的数字专辑。导入整场录音、多段录音或 CD 抓轨文件后，可以边试听边标记分轨点，核对曲名和演出信息，再批量写入英文文件名、专辑标签和封面。分轨与导出由本机 FFmpeg 完成，保留原始录音。  录音分轨与 CD 整理 · 支持多段录音拼接、整轨配合 CUE 分轨，以及已拆分音轨的批量整理。  曲目与场次核对 · 匹配作品编号和乐章，统一专辑标签。可接入自选大模型识别节目单、封面和封底，并在校对后填入项目。  音频处理与导出 · 提供降噪、均衡、增益、限幅和淡入淡出，支持处理前后试听，以及 FLAC、WAV、MP3、MKV 和静态封面视频导出。  项目归档 · 保存音轨来源、分轨点、标签和封面，重新打开项目即可继续编辑。
