# Classical Recording Studio · 古典录音工作台

古典录音工作台是整理现场录音与 CD 抓轨的开源桌面应用，支持 Windows 和 macOS。使用本机 FFmpeg 按时间分轨，可核对曲目与乐章，批量写入英文文件名、专辑标签和封面，按作品和演出场次归档。项目保存后可继续编辑，原始录音会保留。代码采用 MIT 许可证。

**[下载 Windows 和 macOS 发行包](https://github.com/Tamako0626/Classical-Recording-Studio-/releases)**

## Windows 11 / Windows 10 x64

1. 从 Releases 下载 Windows x64 ZIP，解压全部文件，再双击其中的 `Classical Recording Studio.exe`。
2. 安装 [FFmpeg](https://ffmpeg.org/download.html#build-windows)，将包含 `ffmpeg.exe`、`ffprobe.exe` 的 `bin` 文件夹加入 Windows PATH。在新的 PowerShell 中分别运行 `ffmpeg -version` 和 `ffprobe -version` 验证，再启动应用。
3. 打开 **整场录音分轨**，导入 WAV、FLAC、MP3 或 MKV，逐轨选择音频来源和起止点。可先试听，也可选择按顺序拼接。
4. 设置标签、封面、格式和音频处理，点击 **运行 FFmpeg**。首次运行会要求选择保存位置，程序会创建按场次信息命名的专辑子目录。可在「输出设置」预览或自定义名称。上传的 PNG 或 JPEG 封面会在同一目录另存为 `cover.png` 或 `cover.jpg`，并用于嵌入音轨。已有同名异图时会提示换文件夹或移走原文件。完工后点 **在文件夹中显示** 查看结果。

桌面版通过本机 FFmpeg 从磁盘读取录音并直接写入输出目录。没有网页版的单轨 450 MiB 预检查。可处理的文件大小取决于磁盘空间、文件系统和所选格式。现有同名输出会报错，原始录音保留。

升级可关闭旧程序后，将新 ZIP 解压到新文件夹，再运行其中的 EXE。工作区沿用现有的本机数据库。若启动阶段出现错误，程序会显示报错框和诊断日志位置。

## CD 抓轨整理

在「整场录音分轨」页面点击「CD 抓轨整理」。

- **整轨 + CUE**：选择 CUE 及其引用的音频。程序读取 AUDIO 轨、INDEX 01 和 CUE 自带标签，按 CD 每秒 75 帧换算时间；可选封面和封底补充曲目信息。
- **多个独立音轨**：导入已拆分的文件，按文件名的数字顺序排列，可手动调整。粘贴带轨号的文字，或识别封面和封底后核对原文，再匹配各轨曲名。各音轨按完整文件输出。
- 支持 HEIC／HEIF、JPG、PNG 图像。HEIC／HEIF 会转换成 PNG 供本机 OCR 和封面嵌入。核对曲名、文件名和标签后点击「导入分轨页」，再按现有分轨流程输出新文件，保留源音频。

## 单个项目文件

在「录音项目」里打开某个项目并点「保存为本地文件」，可将分轨、标签、设置和项目历史保存为 `.crstudio.json`。在项目列表点「打开项目文件」，可继续编辑。同 ID 不同内容会提示作为副本打开。录音与封面以文件名记录，继续分轨时需重新选择原始文件。

## 数据与服务

- 录音、封面、项目数据库和分轨结果保存在本机。网页版项目需先 **导出备份**，再在桌面版 **导入备份**，并重新选取原始录音文件。
- 在线曲目与乐章匹配使用 MusicBrainz。OCR 首次下载识别语言数据，图片在本机识别。手动封面编辑可用。桌面版未配置任何 OpenAI API 凭据。
- 发行包不含 FFmpeg。用户自行安装 FFmpeg。第三方软件许可证见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 源码运行与发布

需要 Node.js 24、npm、FFmpeg 和 FFprobe。

```powershell
npm ci
npm test
npm start
```

Windows 上执行 `npm run dist:win` 会在 `release/` 生成安装版和便携版。源码上传到自己的 GitHub 仓库后，可在 **Actions → Windows desktop** 手动构建。推送匹配 `v*` 的版本标签会触发 Windows 构建和发布。安装包默认未签名。

### 大模型识别与高级后期处理

- 在桌面窗口右上角打开「LLM 配置」，选择 DeepSeek 或兼容 Chat Completions 的服务，填入服务商提供的 API Key、Base URL 和模型 ID。点击「检查连接」获取可选模型并测试当前模型，然后保存。API Key 使用系统凭据加密，项目文件和工作区备份不包含此设置。
- 「模型识别文件」支持常用图片（含 HEIC/HEIF）、PDF（文本或扫描件）、DOCX 正文、TXT、CUE、CSV、TSV、MD、JSON、XML、SRT 和 VTT。节目单、场次和 CD 抓轨窗口可以把识别结果送回原有校对流程。支持图像的服务可启用图像输入。文字模型接收本机 OCR 提取的文字。识别前会显示目标服务并确认发送。录音标签识别只发送用户确认后的标签、文件名和技术信息。
- 在「整场录音分轨 → 输出设置 → 高级后期处理」选用 FFT / 非局部均值降噪、50 / 60 Hz 去嗡声、去爆点、修复削波、高低通、三频均衡、声道处理、噪声门、压缩、去齿音、EBU R128 或动态响度处理、限幅及淡入淡出。这些选项初始为关闭状态，运行本机 FFmpeg 和生成 PowerShell 脚本时均可使用。

### 模型匹配与处理前后试听

- 在「LLM 配置」使用「刷新模型列表」读取服务支持的模型，从下拉菜单选中模型后检查连接并保存。只知道模型 ID 时可选择「手动输入模型 ID」。
- 在单轨的「匹配文件名」窗口可以生成模型候选，点选一个文件名即可填入；可勾选同时更新 Title 与 Composer。在「展开乐章／分曲」可请求模型返回乐章清单，核对版本并勾选条目后按顺序填回。模型候选需要人工核对。
- 在分轨页的输出设置里点「试听处理效果」，选择某一轨或当前录音，以及开头或结尾片段。播放器提供同一时间段的原始音频和应用当前滤镜参数后的音频，试听使用临时 WAV，关闭窗口会清理试听资源。长录音的结尾片段需要从本轨起点跑滤镜，可能耗时较长。

大幅增加增益时，可在「增益」下方勾选「启用防爆音限幅」。开启后默认使用 −1 dBFS 峰值上限，可按需要调整。限幅应用于试听、导出和生成的 PowerShell 脚本。

「分轨 → 识别场次信息 → 联网核对」可用已有场次字段查找公开演出页面。配置 DeepSeek 官方接口、API Key 和 `deepseek-flash` 后，点击「联网核对」发送场次字段。核对候选的演出日期、地点和来源链接，点「使用此场次」后再将校对表填入分轨页。

关闭桌面程序时，如果分轨项目还没保存，会提供「保存并退出」「不保存并退出」和「取消」。保存并退出会等待工作区写入成功。退出时若仍在处理音频，程序会停止任务，已完成的输出文件会保留。

### 静态封面视频

在桌面分轨页的「分轨结果」选择「制作封面视频」。当前成功导出的音轨会自动列出，也可从磁盘添加已分轨音频。可使用当前专辑封面或选择 PNG/JPG。每条勾选的音轨会单独生成一个 1920 × 1080 H.264 静态画面视频，封面按原比例缩放，成品写入目标目录下的「封面视频」文件夹。

- 「自动」将 48 kHz 及以上的无损音频封装为 MKV，保留原采样率，使用至少 24 bit 的 FLAC/PCM。其余音频生成 H.264/AAC MP4。
- 「全部生成 MKV」会将不足 48 kHz 的音频重采样为 48 kHz，较高采样率继续保留。升频或扩展位深只能改变输出规格。
- 「全部生成 MP4」适用于常规视频。视频封装使用 FFmpeg 的 libx264 和原生 AAC 编码器。

分轨页的「曲目与时间点 → 按场次更新全部标签」会把已填的专辑名、演出日期、演奏家、指挥家和乐团同步到音轨标签。已有曲名、作曲家和轨号保留；可为缺失轨号及明确的单一作曲家补值。支持撤销最近一次批量更新，修改随项目保存并在导出时写入音频。

桌面分轨页的「专辑封面」区可选上传 PNG 或 JPG 封底。导出时，封底以 `back.png` 或 `back.jpg` 保存到音轨所在的专辑文件夹。CD 抓轨窗选好的封底也可直接带入。项目记录封底文件名，重新打开项目后可按需选择原图。

首页「项目列表」可手动新建或删除项目。把排序切到「手动顺序」后，可在每一行上移或下移项目。排序模式和顺序会写入工作区；启用筛选时只在可见项目之间移动。删除项目只移除工作台记录，保留本地录音、导出文件和既有处理记录。

桌面版保存分轨项目时会记住音频、拼接录音、专辑封面和封底。再次打开同一工作区里的项目便会自动载入。原录音通过本机引用关联，若移动或改名，请在缺失音频旁点击「重新关联」，选择同格式文件。生成的拼接音频和封面图片保存在工作台的数据目录。项目文件可在同一工作台中沿用引用，复制到另一台电脑后按需重新关联。旧项目没有文件引用时需要补录保存一次。

桌面版的封面、封底和封面制作支持直接选择 HEIC / HEIF。软件在本机转换为 PNG 后预览、保存和导出。输入的 HEIC / HEIF 文件最大为 20 MB。若转换后超过 30 MB，软件会按原比例缩小以便保存。

在「CD 抓轨整理」确认曲目与专辑标签后，点击「导入分轨页」，封面、封底、专辑名称、演出者、作曲家和专辑日期或年份会一并填入分轨页。分轨页中「专辑标签日期 / 年份（CD）」用于音频 Date 标签，演出日期可以单独记录。

在 CD 抓轨窗口点击「用模型识别封面与封底」，核对后选择「使用校对结果」。专辑标签随即填入表单，已手动编辑的标签优先保留。可准确对应的空白曲目也会填入。直接点击「导入分轨页」，可将图片、专辑标签和曲目一并转入分轨页。

分轨页的「一键转英文并核对」可调用已保存的大模型。窗口内显示将接收场次字段的模型服务。开始核对后，可比较原值和英文建议，勾选要应用的字段。演出日期及空白字段不由模型改写。可使用本机词典，或在「识别场次信息」中联网核对公开演出资料。

## macOS 桌面版

需要 macOS 13 Ventura 或更新版本。Apple 芯片（M 系列）用 arm64 包，Intel 芯片用 x64 包。解压后，把 `Classical Recording Studio.app` 拖到「应用程序」。

应用调用本机 FFmpeg。已安装 [Homebrew](https://brew.sh/) 时，在终端运行 `brew install ffmpeg`。从 Finder 启动的应用也会查找 Homebrew 的常用目录。应用使用本机 FFmpeg 完成分轨和导出，「脚本生成」中的 PowerShell 脚本供 Windows 使用。

发布包采用临时签名，尚未经过 Apple 公证。如 macOS 显示开发者验证提示，可查看 [Apple 的打开方式](https://support.apple.com/102445)。

在 macOS 上构建源码请使用 Node.js 24，执行 `npm ci`、`npm run dist:mac`。输出位于 `release/`。
